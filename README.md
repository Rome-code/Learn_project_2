# Учебный проект по созданию интернет-магазина

**Краткое описание проекта**:

Учебный проект по созданию интернет-магазина на языке Python. В корневой папку проекта
в модуль product добавлен класс Product-класс для создания наименований продуктов и их
параметров, в модуль category.py Category, класс для создания категорий продукции.

**Требования к окружению**:

Python 3.12.5

**Информация о тестах проекта**:
    
В папке tests в файле test_main.py присутствуют тесты.
