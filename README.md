# Учебный проект по созданию интернет-магазина

**Краткое описание проекта**:

Учебный проект по созданию интернет-магазина на языке Python. В корневой 
папку проекта в модуль product добавлен класс Product-класс для создания
наименований продуктов и их параметров, в модуль category.py Category,
класс для создания категорий продукции. Расширены функции вышеупомянутых классов,
в функционал которых добавлены изменения уровня доступа некоторых атрибутов.

**Требования к окружению**:

Python 3.12.5

**Информация о тестах проекта**:
    
В папке tests в файле tests присутствуют тесты для всех модулей.
